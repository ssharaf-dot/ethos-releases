# Release notes format

Use this structure when publishing a release. Check all file links against that release’s assets. Keep historical releases linked to their own tag, not latest.

```markdown
![Ethos Technologies — release notes](https://raw.githubusercontent.com/ssharaf-dot/ethos-releases/main/assets/brand/release-banner.svg)

A short, factual summary of this release.

## Download this release

Ethos Home links for each supported platform.
Individual app download table.
Checksums and installation guide.

## What’s new

Group changes by user-facing outcome or app.
Only include changes delivered in this release.

## Installation and upgrades

Supported systems, upgrade behavior and signing status.

[ETHOS TECHNOLOGIES](https://www.ethostechnologies.si) · [ALL RELEASES](https://github.com/ssharaf-dot/ethos-releases/releases)
```
